# Gap-Finder

**Gap-Finder** combines static call-graph analysis with test coverage reports to pinpoint functions that have **untested lines** *and* are **actively called** by other code in your repository.

Instead of surfacing noisy coverage reports full of unused helpers or dead scripts, Gap-Finder filters out uncalled functions so you—and your AI coding assistant—focus only on high-impact test gaps.

---

## How It Works

1. **AST Call-Graph Extraction (`ast_parser.py` & `graph_builder.py`):** Parses your Python codebase using `ast` (without executing target code) to map functions, class methods, and caller-to-callee edges.
2. **Coverage Intersection (`coverage_reader.py`):** Reads `coverage.json` generated by `coverage.py` and maps missing line numbers to each function's body.
3. **Dead-Code Filtering:** Skips any function with zero incoming callers, highlighting only live functions with untested branches or lines.
4. **CLI & MCP Server (`cli.py` & `mcp_server.py`):** Usable directly from the command line or exposed as an MCP tool for AI coding editors (Cursor, Claude Code, Claude Desktop).

## Installation

Clone the repository and install it in editable mode:

```bash
git clone [https://github.com/Nida-18/Git-Finder](https://github.com/Nida-18/Gap-Finder)
cd Gap-Finder
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

---

## Usage

### 1. Generate a Coverage Report
Inside the Python repository you want to analyze, run your test suite with `coverage`:

```bash
pip install pytest coverage
coverage run -m pytest
coverage json
```

### 2. Run Gap-Finder via CLI
Point `gap-finder` at the target repository:

```bash
gap-finder /path/to/target-repo --coverage coverage.json
```

**Example Output:**
```text
Found 1 active functions with coverage gaps:

- billing.calculate_discount (billing.py)
  Untested: 1/3 lines [6]
  Called by (1): billing.checkout
```

## MCP Server Setup (AI Coding Assistants)

Gap-Finder includes a built-in Model Context Protocol (MCP) server exposing the `get_active_coverage_gaps` tool.

Add the following configuration to your AI editor's MCP settings (e.g., `.cursor/mcp.json` or `claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "gap-finder": {
      "command": "/absolute/path/to/Gap-Finder/.venv/bin/python",
      "args": ["-m", "gap_finder.mcp_server"]
    }
  }
}
```

Once connected, ask your AI assistant:
> *"Run `get_active_coverage_gaps` on this repo and write unit tests for the missing lines."*

## Project Structure

```text
gap_finder/
├── __init__.py          # Package exports
├── models.py            # FunctionInfo and CoverageGap dataclasses
├── ast_parser.py        # Static AST walker for functions, methods, and calls
├── coverage_reader.py   # Maps coverage.json missing lines to function bodies
├── graph_builder.py     # Builds caller-callee graph and ranks coverage gaps
├── cli.py               # Terminal entry point
└── mcp_server.py        # FastMCP tool server
```
